# augmented-ocean-eye

Here I am messing aroung with AIS-Data and in the Future with OpenCV

## start hacking

  - Make a virtualenv

```
$ virtualenv -p /usr/bin/python3 aoe
```

  - Install dependencies

```
(aoe) $ pip install -r requirements.txt
```

  - Run some code

```
(aoe) $ ./calc-polygon.py
(aoe) $ ./decode-ais.py
```
